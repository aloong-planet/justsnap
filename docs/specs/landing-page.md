# 官网下载页

> 关联：[ADR-0004](../adr/0004-distribute-one-apple-silicon-package.md)（只发布一个 Apple 芯片安装包）· [ADR-0007](../adr/0007-direct-distribution-only-for-v1.md)（v1 只做直接分发）

## Problem Statement

没见过本仓库的人，需要一个地方了解随译（JustSnap）做什么、怎么装、并下载它。GitHub 仓库页写给已经在 GitHub 上的人。发布的版本会一个接一个出现，下载页必须每次都提供当前的正式版，而不需要有人去改页面。

## Solution

仓库里的 `site/` 项目，用 Astro 构建，由 Cloudflare Pages 部署在 `justsnap.aloongplanet.com`，中文在 `/`，英文在 `/en`。它是一页长页：顶栏、占满第一屏并带下载按钮的首屏、随滚动切换步骤的功能展示区、含下载区与三步安装的“下载与安装”区和页脚。访客的浏览器决定提供哪个下载：先读 R2 上的最新版指针；读不到就读 GitHub 公开的 Releases 接口；两处都读不到就提供 GitHub 的发布列表。因此发布新版本不需要改站点。

## User Stories

### landing-page::US-001 了解随译并下载

作为访客，我想一眼看到随译做什么并一键下载，这样我不用读仓库就能试用。

- landing-page::US-001/AC-01：首屏显示名称、一段说明、下载按钮、平台行“macOS 14.4 或更高 · Apple 芯片”，以及一张截图。
- landing-page::US-001/AC-02：存在正式版时，首屏按钮直接下载该版本的 Apple 芯片 DMG。
- landing-page::US-001/AC-03：页面无法判断存在哪个版本时，按钮仍通向下载：GitHub 的发布列表。

### landing-page::US-002 用我的语言阅读

作为访客，我想用中文或英文阅读页面，这样读起来顺畅。

- landing-page::US-002/AC-01：中文在 `/`，英文在 `/en`；顶栏右侧的切换器在两者之间切换。
- landing-page::US-002/AC-02：两种语言有相同的章节、相同的下载状态，以及各自一套截图。

### landing-page::US-003 看到 App 的主要用法

作为访客，我想看到 App 的主要用法和每项的简短说明，这样我知道自己会得到什么。

- landing-page::US-003/AC-01：功能展示区按顺序给出六步——选取屏幕区域、提取文字、翻译、粘贴图片或文字、历史与重试、使用自己的模型服务商——每步配一张该用法的截图（landing-page::REQ-004、landing-page::REQ-005）。
- landing-page::US-003/AC-02：翻译一步说明目标语言可随时更换；最后一步说明密钥保存在 macOS 钥匙串，截图只发送给访客自己选的模型服务商。

### landing-page::US-004 知道安装要做什么

作为访客，我想知道安装步骤和首次启动会出现什么，这样系统的提示不会吓到我。

- landing-page::US-004/AC-01：三步：用其上的下载按钮得到 DMG；打开它，把随译拖进“应用程序”；打开应用。
- landing-page::US-004/AC-02：第三步说明 macOS 会提示 Apple 已检查过它没有恶意软件，点“打开”即可；应用会引导授予屏幕录制权限并添加模型服务商的 API Key；有新版本时菜单栏面板出现更新提示。

## Functional Requirements

### landing-page::REQ-001 决定提供什么下载

- landing-page::REQ-001/AC-01：访客的浏览器读到 R2 最新版指针时，页面进入 R2 正式版状态，版本取指针里的版本。
- landing-page::REQ-001/AC-02：指针不存在或读不了（离线、被拦截、格式错误）时，页面读 GitHub 公开的 Releases 接口，取最新的正式版发布，进入 GitHub 正式版状态，全部链接指向 GitHub。预发布版本不被提供。
- landing-page::REQ-001/AC-03：两处都读不了，或 GitHub 没有任何正式版发布时，页面显示列表状态。
- landing-page::REQ-001/AC-04：页面首次送达时，即脚本运行之前（以及不运行脚本的访客），处于列表状态。
- landing-page::REQ-001/AC-05：发布任何版本都不需要编辑或重新部署站点。

### landing-page::REQ-002 各状态显示什么

- landing-page::REQ-002/AC-01：**R2 正式版**：首屏按钮写“下载随译 <版本>”（英文“Download JustSnap <version>”），从下载域名下载 DMG；其下是平台行和链接“在 GitHub 查看所有版本”；下载区写“当前版本 <版本>”，一行两个按钮：下载（R2 的 DMG）和 GitHub（同一个 DMG 在 GitHub 上）。
- landing-page::REQ-002/AC-02：**GitHub 正式版**：同 AC-01，但所有链接都指向 GitHub，下载区一行只有一个下载按钮。该版本的发布没有 DMG 时，按钮通向该发布的页面。
- landing-page::REQ-002/AC-03：**列表**：首屏按钮写“从 GitHub 下载随译”，通向发布列表；按钮和平台行里都没有版本号；下载区写“暂时无法读取版本信息，请前往 GitHub 下载”，一个按钮“前往 GitHub 下载”。
- landing-page::REQ-002/AC-04：指向 GitHub 的链接在新标签页打开；R2 的下载在原页开始。

### landing-page::REQ-003 页面结构

- landing-page::REQ-003/AC-01：顶栏有品牌（landing-page::REQ-008）、导航（功能、下载与安装、GitHub，窄于 760px 时隐藏）和语言切换器，滚动时停在顶部。
- landing-page::REQ-003/AC-02：顶栏之下依次是首屏、功能展示区、“下载与安装”区、页脚。“下载与安装”区先是下载区，再是三步安装（landing-page::US-004）；页脚有 GitHub、发布列表链接和版权行。
- landing-page::REQ-003/AC-03：内容宽度上限 1280px。宽于 900px 时，首屏恰占满顶栏之下的一屏：左侧是名称、说明和下载块，右侧的截图放大到整张都在这一屏内，功能展示区的顶端恰在首屏之下。不宽于 900px 时，首屏按内容高度排列，截图在文字下方，宽度占满内容宽度。

### landing-page::REQ-004 固定的功能展示区

- landing-page::REQ-004/AC-01：宽屏时，页面滚过展示区期间，展示区固定在顶栏之下。左侧窄栏显示当前步骤的序号和总数（如“03 / 06”）、标题和说明；该步骤的截图在右侧放大，整张都在顶栏之下，窗口再矮也如此；没有进度圆点，也没有滚动提示。
- landing-page::REQ-004/AC-02：切换步骤时，其文字和截图在原位一起交叉淡入淡出：没有东西移动，每步的文字都从同一行开始。减少动态效果的访客看到的是即时切换。只有当前步骤的文字和截图对指针和辅助技术可见。
- landing-page::REQ-004/AC-03：窄于 760px 时不固定。每一步各自的截图在其文字下方，与下一步标题之间有明显间隔。
- landing-page::REQ-004/AC-04：切换语言保持当前步骤和滚动位置。
- landing-page::REQ-004/AC-05：页面照常滚动，不拦截滚轮。展示区固定的那一刻显示第一步；当前步骤取自展示区固定之后滚过的距离除以窗口高度的 60% 所得的数，四舍五入并限制在第一步到最后一步之间，往回滚则往回切；展示区固定之前显示第一步，滚过之后显示最后一步。展示区占据的滚动长度为窗口高减去顶栏高，再加每多一步 60% 窗口高。

### landing-page::REQ-005 截图

- landing-page::REQ-005/AC-01：首屏截图和六张功能截图由构建出的 App 自己的界面视图离屏渲染而成，不是对运行中的 App 或使用者屏幕的捕获；内容是虚构的示例（示例文字、示例对话），不出现使用者本人的数据；每种语言一套，浅色外观。
- landing-page::REQ-005/AC-02：六张功能截图宽高比 16:9、缩放一致，使文字在步骤切换时大小不变；每张在列表行之间截断。
- landing-page::REQ-005/AC-03：每张截图的位置在加载前就已占住，页面不跳动。
- landing-page::REQ-005/AC-04：站点的生产构建在任意两张截图是同一个文件时失败，因此一套重复的占位图不会被发布。

### landing-page::REQ-006 文案（直接验收）

文案只有中文和英文。中文页称产品“随译”，括注 JustSnap 于品牌与首屏；英文页称 JustSnap。提到模型服务商时只举例而不当作全集（“OpenAI、Gemini、DeepSeek 等”）。页面使用跟随访客系统外观的浅色与深色两套配色。功能展示区的标题中文为“一个快捷键，从屏幕到文字”，英文为“From screen to text in one shortcut”；其副标题中文为“不做标注，也不先过传统 OCR：原图直接交给视觉模型。”，英文为“No annotation tools, no classic OCR step: the original image goes straight to a vision model.”。安装步骤的标题中文为“三步装好”，英文为“Installed in three steps”。

### landing-page::REQ-007 首屏标题与说明（直接验收）

首屏标题中文为“截一块屏幕，直接提取文字或翻译”，英文为“Snap any part of your screen. Get the text or the translation.”。首屏说明中文为“随译（JustSnap）是 macOS 菜单栏里的截图工具：框选任意区域，几秒内拿到提取的文字或译文。用你自己的模型服务商。”，英文为“JustSnap lives in your Mac's menu bar. Select any region, and seconds later a vision model hands back the text or the translation. Bring your own provider.”。

### landing-page::REQ-008 应用标识（直接验收）

顶栏以应用图标加文字“JustSnap”（中文页“随译 JustSnap”）作标识；图标只作装饰，读屏软件只读文字。浏览器标签页使用应用图标，SVG 为主，PNG 为后备。

## Quality Requirements

### landing-page::QR-001 布局在各宽度、语言和外观下成立

适用范围：整页，两种语言、两种外观、三种下载状态。

- landing-page::QR-001/AC-01：在 400、900、1280、1440px 宽度下，页面不横向滚动，每个按钮都在其卡片内，首屏保留两侧边距。

### landing-page::QR-002 文字可读

适用范围：整页的文字，两种外观。

- landing-page::QR-002/AC-01：首屏说明、功能说明和卡片里的文字用正文色；次要色只用于平台行、序号这类附注。
- landing-page::QR-002/AC-02：每种文字色对其所在底色的对比度不低于 4.5:1。

## Constraints

### landing-page::CON-001 站点放在哪里（直接验收）

适用范围：下载页。站点是本仓库的 `site/` 项目，用 Astro 构建，由 Cloudflare Pages 部署在 `justsnap.aloongplanet.com`；不是单个静态文件，也不是另一个仓库。

### landing-page::CON-002 两种语言（直接验收）

适用范围：站点的每个页面和字符串。只有中文和英文，与 App 的界面语言一致（ADR-0003）。

### landing-page::CON-003 页面读取什么（直接验收）

适用范围：访客的浏览器。页面只读 R2 最新版指针和 GitHub 公开的 Releases 接口，不读其他来源，来判断提供什么下载。

### landing-page::CON-004 只提供 Apple 芯片安装包（直接验收）

适用范围：下载页的全部下载入口和文案。页面只提供 Apple 芯片的 DMG，不提供 Universal 和 Intel 的 DMG，也不提及它们。

## 失败模式与边界

**序列 A：决定下载**

- A1 尚无任何发布：没有指针，GitHub 也没有 → 列表状态，通向空的发布列表。
- A2 指针读不了（跨域、网络、超时、内容畸形）→ 走 GitHub 路径（landing-page::REQ-001/AC-02）；页面从不猜版本。
- A3 GitHub 限流或返回错误 → 视为读不了（landing-page::REQ-001/AC-03）。
- A4 一个新正式版刚在 GitHub 发布、向 R2 的镜像还在进行 → 指针仍指向上一个正式版，页面从 R2 提供它，直到指针更新；第一个正式版此时还没有指针，由 GitHub 以 GitHub 正式版状态提供。
- A5 一次读取在页面显示之后才完成 → 状态原地更新；在此之前列表状态本身就是有效的下载方式。访客若已滚过首屏的下载块（滚动过，或切换语言后被放回那里），所看的内容不随之移动。
- A6 GitHub 返回的内容含草稿，或某个发布没有 Apple 芯片 DMG → 草稿被忽略；没有 DMG 的发布不被当作直接下载提供，页面给出它的发布页。
- A7 GitHub 只有预发布版本 → 列表状态。

**序列 B：语言与导航**

- B1 直接访问 `/en` → 英文，切换器在 EN；切换则去另一种语言的页面。
- B2 导航里的 GitHub 链接在新标签页打开仓库；章节链接在页内滚动。

**序列 C：功能展示区**

- C1 快速滚动，或跳到下载区再回来 → 展示区显示滚动位置给出的步骤，绝不是跳转之前留下的那一步。
- C2 跨过 760px 调整大小，或改变窗口高度 → 版式在固定展示区和堆叠步骤之间切换，所显示的步骤跟随新高度下的滚动位置，没有陈旧步骤。
- C3 矮窗口 → 截图缩小，整张仍在顶栏之下（landing-page::REQ-004/AC-01）。
- C4 屏幕阅读器在宽屏上只遇到当前步骤，其余步骤靠滚动到达（landing-page::REQ-004/AC-02）。
- C5 不运行脚本的访客 → 任何宽度下都显示堆叠步骤，每步配截图。

**序列 D：外观**

- D1 浅色与深色都有页面配色；切换系统外观会重新着色。截图取自浅色外观，在两种外观下都保持浅色。

**引入内容**

- E1 指针和 GitHub 的返回是外部数据。只有经过校验的版本号和位于预期主机（下载域名和 github.com）的 URL 才会进入页面，作为文字和链接目标；发布说明和其他发布文字绝不插入页面。

## Implementation Decisions

- **最新版指针**：下载域名根下的 `latest.json`，形如 `{ version, files: [{ name, arch, size, url }] }`。页面只在 `version` 是正式版本号（`主.次.修订`，没有后缀）、`files` 中有 `arch` 为 `arm64` 的一项、其 `name` 为 `JustSnap-<版本>-mac-arm64.dmg`、且 `url` 恰为 `https://dl.justsnap.aloongplanet.com/releases/v<版本>/<name>` 时才采用；其余情形都视为读不了，404 表示还没有指针。指针里的其他架构条目被忽略。
- **GitHub 读取**：对 `aloong-planet/justsnap` 的未认证公开 REST 接口，请求一次取前一百个发布。一个发布算数的条件：已发布（草稿忽略）、不是预发布、tag 为 `v` 加正式版本号。取发布时间最新的；不依赖返回的顺序。一个发布的 DMG 只在上传完成后才算数。
- **判断状态是一个纯函数**：输入是两次读取的结果（指针：一个版本、不存在或读不了；GitHub：最新正式版、没有、或读不了），输出是三种状态之一。一小段浏览器脚本执行读取并应用结果；送达的 HTML 渲染列表状态。
- **两次读取**都在五秒后放弃（失败 A2），不发送任何需要 CORS 预检的头。每个链接都由校验过的版本构造，绝不取自返回内容（失败 E1）。
- **应用状态**：原地、按文字替换首屏的下载块（按钮，以及其下的平台行与链接）和下载区的文字与按钮行；列表状态重建送达时的标记。状态在首屏下载块位于访客视野之上时落地的，页面按该块的变化量滚动，使访客所看的内容不动；块在视野内时则在视野内变化（失败 A5）。
- **配色**：取自 App 历史页的蓝灰色板——页面底色与文字取其浅色与深色值，强调色取其“类型”蓝（浅 `#1553B2`，深 `#9BC0FF`）；浅色与深色都声明，由系统外观切换。字体用系统字体栈，页面不加载网络字体。图标用复制自 Lucide 的内联 SVG（下载等）。
- **语言切换器**是指向另一种语言页面的链接，没有脚本也能用。离开之前，脚本记下视野中的元素、它到窗口顶部的距离和当前步骤；另一页把同一元素放回同一距离，并让同一步骤成为当前步骤（landing-page::REQ-004/AC-04）。记元素而不是滚动偏移，因为两种语言的文字折行高度不同；固定的展示区从不充当那个元素。
- **截图**以静态资源发布，宽高写明。

## Out of Scope

- Universal 和 Intel 安装包的下载入口：发行只有一个 Apple 芯片安装包（ADR-0004），页面不提供也不提及（landing-page::CON-004）。
- 预发布版本的下载状态：目前没有预发布通道。
- 下载统计。
- 两种语言之外的语言。
- 面向中国大陆的页面副本。
- 在页面上显示发布说明（失败模式 E1）。
- 在步骤间点击或按键切换：展示区一次显示一步，随滚动切换（landing-page::REQ-004/AC-05）。

## Further Notes

- 指针的形状按本 spec 的 Implementation Decisions 为准；下载域名根下的 `latest.json` 由镜像工作流更新（release-mirror::REQ-001/AC-01、release-mirror::REQ-004/AC-01）。
